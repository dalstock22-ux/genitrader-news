# genitrader-news

GeniTrader 홈페이지가 불러오는 **공개 데이터 저장소**입니다. 이 저장소의 파일은 누구나 볼 수 있으므로
뉴스 제목·출처·링크·직접 쓴 요약, 그리고 공개용 리포트(PDF)만 올립니다. 토큰·키·개인정보는 올리지 않습니다.

## 파일
- `news.json` — 오늘의 브리핑, 시세 요약, 뉴스 목록
- `reports.json` — 테마 분석 리포트 목록
- `reports/` — 리포트 PDF 파일

## news.json 형식
```json
{
  "updated": "2026-11-10T08:20:00+09:00",
  "market": [{ "name": "금", "value": "4,120.5", "change": "+0.4%" }],
  "brief": { "headline": "한 줄 요약", "points": ["핵심 1", "핵심 2"] },
  "items": [
    {
      "category": "미국증시 | 한국증시 | 금·원자재 | 거시·정책",
      "title": "제목", "source": "출처", "url": "https://...",
      "summary": "직접 쓴 한두 줄 요약", "published": "2026-11-10T07:40:00+09:00"
    }
  ]
}
```

## reports.json 형식
```json
{
  "items": [
    { "title": "주간 테마 분석 리포트", "date": "2026-11-09", "file": "reports/2026-11-09.pdf",
      "themes": ["테마 A", "테마 B"], "summary": "배경과 흐름 요약" }
  ]
}
```

## 원칙
- 기사 본문을 옮기지 않습니다(제목·링크·직접 쓴 요약만). 저작권은 각 언론사에 있습니다.
- 모든 자료는 참고용이며 특정 종목의 매수·매도 추천이 아닙니다.
